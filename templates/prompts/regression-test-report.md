This step has a regression-test gate. Write the regression test first and watch it fail. Then add `"regressionTest": {"file": "<repo-relative test file under tests/>", "name": "<test name>"}` to the result JSON. A script, never you, runs that test on the base with your fix reverted and on your head and records the exit codes; it must fail on the base and pass on the head. The name must select only that test, because it is passed as `-t <name>`. Without `regressionTest` the step fails.
